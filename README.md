# Capstone Project: Oncology Dashboard using Apple S621
An iPadOS application that uses Apple HealthKit data to surface early patterns that may indicate elevated cancer risk trends for clinician review.

## Our Purpose
This project explores whether longitudinal physiological and behavioral data from Apple HealthKit can be used to identify risk related patterns and deviations over time.
The goal is to support clinicians by surfacing health trends and anomaly signals. 

## Key Features
* HealthKit integration for longitudinal patient data
* Apple intelligence integration into appointment summaries
* Clinician dashboard (IPadOS)
    * iPad-optimised clinician interface for patient review
    * Radar graph for multidomain health snapshot visualization
    * Timeline view of patient health progression and key clinical events
* Multidomain trend visualization of key health indicators
  * Self-reported symptoms
  * Physiological metrics
  * Sleep patterns
  * Activity levels
* Clinical events tracking
  * Appointment records
  * Reported symptoms
  * Medical events (eg. emergencies)


## Getting Started
### Requirements:
* Xcode 15+
* iPadOS 
* Apple Developer Account (for HealthKit entitlement)

## **_Clinical Disclaimer_**
